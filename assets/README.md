# assets/

- `avatar.svg` — generated gradient monogram used on the About section. Swap it
  for a real headshot if you want (keep the filename `avatar.jpg`/`.png` and
  update the `src` in `index.html`, or just overwrite `avatar.svg` with your
  own SVG of the same name).
- `resume.pdf` — **not included yet.** The site already links to
  `assets/resume.pdf` in two places (hero button and Contact section). Drop
  your resume PDF into this folder with that exact filename and both links
  will work immediately — no HTML changes needed.
